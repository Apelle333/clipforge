# Demo asset provenance

`editor.png` and `editor-mobile.png` are real screenshots of the running editor
using an isolated synthetic test job. `demo.gif` is a silent seven-second excerpt
of an actual H.264/AAC pipeline export, not a mocked editing screen.

The source fixture animates the NASA Eileen Collins image distributed with
scikit-image, documented as public domain:
https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut

The pictured person is not speaking the generated test narration and does not
endorse CLIPFORGE. Audio is intentionally omitted from the public GIF. Original
test text and screenshot/demo contributions are offered under CC0-1.0 to the
extent we own rights; this does not change the NASA image's public-domain status
or the separately licensed application code/fonts. No private user footage or
transcripts appear in these assets.
